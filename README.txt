Jumping Jack

Main Features
Plataformer
Developed in Unity
Supports mouse and keyboard, as well as any type of gamepad

Installation Instructions
No installation required. Just run the .exe file and you're ready to go.

How to Play
Basic controls: AWSD. The rest of the controls are explained in the tutorial.
